    What you are looking at
    
      
    
        postcss-viewport-fallback is a PostCSS plugin. It gives dvh, svh, lvh and the
        other dynamic viewport units a vh / vw fallback that older browsers really apply:
        in calc(), next to var(), in custom properties, @media, @container and @keyframes.
        The plugin itself runs on this page, so the output is exactly what your build
        would get.
      
    
      
    Add it to a project
    
      
    npm install --save-dev postcss postcss-viewport-fallback
